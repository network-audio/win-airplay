Win AirPlay 1.2.1 advertises its receiver as **`<computer name> Input`**. The installer now allows local subnet AirPlay connections on Public as well as Private Windows network profiles. Receiver connection and handshake steps appear in the rotating controller log to help diagnose failed connections without logging pairing payloads.

Download the installer for your Windows architecture below, run it, and approve the administrator prompt. Restart Windows if prompted. Logs are at `%LOCALAPPDATA%\WinAirPlay\controller-usbip.log` and rotate at 1 MiB, retaining at most two files.
