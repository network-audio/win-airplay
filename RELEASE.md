Win AirPlay 1.2.4 keeps the controller running across laptop sleep and network changes. The scheduled launcher now runs on battery power, has no execution time limit, and is retried every minute if it stops unexpectedly. Repeated controller failures use a delay that grows from five seconds to one minute.

Download the installer for your Windows architecture below, run it, and approve the administrator prompt. Restart Windows if prompted. Logs are at `%LOCALAPPDATA%\WinAirPlay\controller-usbip.log` and rotate at 1 MiB, retaining at most two files.
